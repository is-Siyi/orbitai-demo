# OrbitAI · 全域营销智能体平台（真实可运行 Demo）

> 一个品牌需求，一支 7×24 在线的 AI 营销团队。
>
> 不是写死文案的静态原型：**接入你自己的大模型后，7 个 Agent 与创意中心都会发起真实 LLM 调用、流式输出，产物在节点间真实流转。**

本仓库为**蓝色光标 AI Builder（产品经理）岗位**的求职作品。单文件、无后端、无构建，双击即可运行；API Key 仅保存在本机浏览器，不经过任何第三方服务器。

## 一、快速开始（3 步）

1. 用 Chrome / Edge 打开 `orbitai-demo.html`。
2. 点击右上角「**模型设置**」，选择厂商并填入 API Key，点「保存并测试连接」，看到「连接成功」。
3. 进入「**智能体工作室**」点「启动工作流」，或在「**创意内容中心**」点「生成内容」，即可看到真实流式生成。

蓝色光标是全球前十营销传播集团，核心战略 **AI²（All in AI）+ 全球化 2.0**：

### 产品定位

**面向品牌市场团队与蓝标客户经理/优化师的 AI Native 营销战役编排工作台**，把「洞察—策略—创意—本地化—达人—投放—复盘」全链路做成可编排的多智能体工作流，人机协同、全球多市场可用。

## 三、真实运行机制（与静态原型的区别）

### 1. 每个 Agent 都是一次真实调用

工作流 9 个节点（7 Agent + 2 人工 Gate）。每个 Agent 携带自己的角色系统提示词，读取**真实 Brief 与全部前序节点的真实产出**，调用模型生成；上一节点的输出作为上下文进入下一节点，而不是播放预置脚本。

```
洞察官 → 策略官 → 【人工 Gate 策略评审】→ 创意官 → 本地化官
       → 【人工 Gate 内容评审】→ 达人官 → 投放官 → 数据官
```

- **人工 Gate 可暂停/回退**：可填具体调整意见，选择「要求调整」后回退上一节点用真实调用重新生成，再回到审核。
- **流式可见**：生成过程逐字输出，可随时「停止」（AbortController）。
- **预算与排期是真实计算**：按 Brief 预算与市场参数实时算出分配金额与甘特排期，非静态文案。

### 2. 创意内容中心：开放式生成，无模板

- 单次开放式 LLM 调用，按真实品牌/产品/卖点/语气/人群/语种生成，**改任意输入结果即不同**。
- 切换语种由模型按目标语言真实重写（中文卖点会被意译而非保留）。
- 生成后自动发起一次**评审模型调用**：按四维（卖点相关性、本地化表达、品牌语气、行动号召）真实打分并判断合规，返回 JSON 解析；评估失败会诚实提示，不伪造分数。

### 3. 真实可用的工具动作

- 「导出战役方案」生成可下载的 **Markdown 文件**；「存为模板」「采纳入库」写入本机 localStorage。
- 全局 `Ctrl/⌘+K` 命令面板：导航、模型设置、模板载入、决策记录，支持过滤与键盘操作。
- 产品页「决策记录」以「选择 / 放弃 / 理由」呈现 6 项关键取舍，呼应 JD 的独立判断与权衡。

## 四、量化评估体系

- **业务价值层**：ROAS、GMV 达成率、品牌搜索量、GEO 位次 —— 对齐客户 KPI。
- **产品质量层**：一次采纳率、人工修改率、合规拦截率、时延与稳定性 —— 驱动 Agent 迭代。
- **规模成本层**：千次任务 Token 成本、模板复用率、人均并行战役数 —— 验证规模化。

## 五、技术栈与目录

- **原生实现**：HTML + CSS + 原生 JavaScript，无框架、无构建、无后端；`fetch` + SSE 流式解析。
- **图表**：ECharts 5.5（jsDelivr CDN）。

```
orbitai-demo/
├── orbitai-demo.html   # 单文件完整产品
└── README.md
```

### 部署到 GitHub Pages

1. 推送到 GitHub 仓库，`Settings → Pages → Source` 选择分支与根目录。
2. 访问 `https://<用户名>.github.io/<仓库名>/orbitai-demo.html`。
3. 注意：GitHub Pages 为 HTTPS 环境，调用厂商接口同样走 HTTPS，无混合内容问题；若某厂商不允许浏览器跨域（CORS），会原样报错，可换用支持 CORS 的厂商。

## 六、边界说明（诚实披露）

- 本 Demo **不含内置 Key、不提供后端代理**：智能输出完全依赖你接入的真实模型，无 Key 时不生成、不造假。
- 「效果评估」页的图表与工作台部分指标为**演示口径的示例数据**，用于展示度量形态；真实产品中由投放与监测系统回流。
- 浏览器直连的代价是依赖厂商 CORS 与本地网络；企业版会增加后端密钥管理、权限与审计，已在架构与路线图中体现。
- 产品概念基于蓝色光标**公开业务信息独立设计**，不代表官方产品。
